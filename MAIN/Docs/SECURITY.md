# Périmètre de confiance

Les médias viennent d'un dossier choisi dans le sélecteur. Le scan ignore les liens symboliques vers des fichiers et ne suit pas les liens vers les sous-dossiers. Les sondes ffprobe s'exécutent avec délai maximal et protocole file. La base locale est distincte des médias et valide chaque mise à jour par transaction SQLite.

Les playlists autorisent HTTP, HTTPS et RTSP. Une playlist inconnue peut pointer vers un serveur tiers ou LAN. Le lecteur est démarré avec une liste d'arguments. Les comptes des plateformes sont saisis dans un profil Firefox privé et dédié. Le catalogue de démonstration n'accède à aucun service tiers.

La session X11 est installée séparément sur demande. Pour la retirer, supprimer uniquement /usr/share/xsessions/n3xvs-multimedia.desktop. Aucune opération de partitionnement ni de modification d'IA-TB.
